# Instrucciones para Bolt.new

## ⚠️ IMPORTANTE

Este proyecto tiene su código fuente del frontend en la carpeta `frontend/`, pero está configurado para hacer deploy desde el **root**.

## Comandos

- `npm run dev` - **Comando por defecto** - Conecta al VPS en modo producción
- `npm run dev:local` - Desarrollo local (proxy a localhost:8080)
- `npm run prod` - Producción (igual que dev - conecta al VPS)
- `npm run build` - Compilar para producción

⚠️ **Bolt ejecuta `npm run dev` automáticamente**, que está configurado para conectar al VPS externo.

## No Modificar

Los siguientes archivos en el root son necesarios para Bolt y NO deben modificarse manualmente:

- `vite.config.ts` (tiene `root: "frontend"`)
- `tailwind.config.js` (tiene rutas a `./frontend/**`)
- `package.json` (scripts de deployment)
- `.env.production` (variables del VPS)

## Desarrollo

Para hacer cambios al frontend, editar archivos en `frontend/src/`.

El build se genera automáticamente en `dist/` cuando se ejecuta `npm run build`.
