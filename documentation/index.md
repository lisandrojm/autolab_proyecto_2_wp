# Documentación del Proyecto: Autolab / Weprodu

Este proyecto es una plataforma integral de gestión empresarial (ERP) enfocada en la administración de recursos humanos, proyectos, clientes y procesos administrativos (pedidos, vacaciones, notificaciones).

## Estructura de la Documentación

### [Backend](./backend/index.md)
- **Modelos y Schemas**: Estructura de datos en MongoDB.
- **Rutas y Endpoints**: Listado de módulos de la API (HR, Proyectos, Clientes).
- **Servicios y Utilidades**: Lógica de negocio centralizada.

### [Frontend](./frontend/index.md)
- **Arquitectura**: Stack tecnológico (React, Tailwind CSS, Vite).
- **Páginas y Vistas**: Guía de los módulos de la interfaz (Usuarios, Vacaciones, Órdenes).
- **Componentes y Modales**: Patrones de UI reutilizables.

## Tecnologías Principales

- **Servidor**: Node.js con Express, TypeScript, Mongoose.
- **Cliente**: React con TypeScript, Vite, Tailwind CSS.
- **Base de Datos**: MongoDB.
- **Otras**: JWT para autenticación, validaciones con Express-validator, gestión de PDFs.
